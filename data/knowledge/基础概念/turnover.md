# 换手率

> 换手率是成交量相对于流通股本的比率，是衡量股票交易活跃度的标准化指标。

## 定义

换手率（Turnover Rate）是指在一定时间内市场中股票转手买卖的频率，计算公式为成交量除以流通股本。换手率消除了股本大小的影响，使得不同股票之间的活跃度可以直接比较。

对程序员来说，换手率就像一个"归一化指标"——把不同规模系统的请求量都转换成统一的百分比来比较。

## 核心内容

### 换手率的计算

$$\text{换手率} = \frac{\text{当日成交量}}{\text{流通股本}} \times 100\%$$

- **流通股本**：可以在二级市场自由交易的股票数量（不包括大股东锁定的股份）
- 换手率10%意味着当日流通股本中有10%被交易了一次

### 换手率的解读标准

| 换手率区间 | 状态 | 含义 |
|-----------|------|------|
| < 1% | 极低 | 交投清淡，无人关注 |
| 1%-3% | 温和 | 正常交易，无异常 |
| 3%-7% | 活跃 | 有资金关注，可适当留意 |
| 7%-10% | 高度活跃 | 主力资金可能在运作 |
| 10%-15% | 高换手 | 多空分歧大，需警惕 |
| > 15% | 超高换手 | 可能是新股、重大事件、主力出货 |

### 高换手率与低换手率

**高换手率的可能原因：**
- 重大消息刺激（利好或利空）
- 主力资金大量买入或卖出
- 新股上市初期
- 题材炒作的热门股
- 股价接近历史高点或低点

**低换手率的可能原因：**
- 无重大消息，市场平静
- 大盘股（本身股本大，换手率天然低）
- 长期横盘的"僵尸股"
- ST类股票（参与者少）

### 换手率与股价走势

| 换手率 | 价格上涨 | 价格下跌 |
|--------|---------|---------|
| 高换手 | 上涨动力强，但可能是顶部 | 恐慌抛售，可能继续下跌 |
| 低换手 | 上涨乏力，难以持续 | 抛压减轻，可能见底 |

### 举例说明

股票A：流通股本1亿股，当日成交量500万股
- 换手率 = 500万 / 1亿 = 5%
- 属于"活跃"状态

股票B：流通股本20亿股，当日成交量500万股
- 换手率 = 500万 / 20亿 = 0.25%
- 属于"极低"状态

两只股票成交量相同，但换手率相差20倍，说明股票A的交易活跃度远高于股票B。这就是为什么需要换手率而不是直接用成交量来比较。

## 计算公式

**换手率：**
$$\text{换手率} = \frac{\text{成交量}}{\text{流通股本}} \times 100\%$$

**平均换手率：**
$$\text{平均换手率}_N = \frac{1}{N} \sum_{i=1}^{N} \text{换手率}_i$$

**换手率比（相对活跃度）：**
$$\text{换手率比} = \frac{\text{当日换手率}}{\text{N日平均换手率}}$$

## Python 代码

```python
import akshare as ak
import pandas as pd

# 获取股票日K线（包含换手率）
df = ak.stock_zh_a_hist(symbol="600519", period="daily",
                         start_date="20240101", end_date="20240630",
                         adjust="qfq")

# 换手率已在数据中（'换手率'列）
print("换手率统计:")
print(df['换手率'].describe())

# 计算换手率均值和标准差
df['换手率_MA5'] = df['换手率'].rolling(5).mean()
df['换手率_MA20'] = df['换手率'].rolling(20).mean()

# 换手率异常检测（超过2倍标准差）
mean_turnover = df['换手率'].mean()
std_turnover = df['换手率'].std()
df['换手率异常'] = df['换手率'] > (mean_turnover + 2 * std_turnover)
print(f"\n换手率异常天数: {df['换手率异常'].sum()}")

# 换手率分位数分析
percentiles = df['换手率'].quantile([0.1, 0.25, 0.5, 0.75, 0.9])
print("\n换手率分位数:")
print(percentiles)

# 高换手率后续走势分析
high_turnover = df[df['换手率'] > df['换手率'].quantile(0.9)]
for idx in high_turnover.index:
    if idx + 5 < len(df):
        future_ret = df.loc[idx+5, '收盘'] / df.loc[idx, '收盘'] - 1
        df.loc[idx, '5日后涨跌'] = future_ret

print(f"\n高换手率后5日平均涨跌: {high_turnover['5日后涨跌'].mean():.2%}")
```

## 常见误区

1. **"换手率高说明股票好"** — 换手率高只说明交易活跃，并不代表股票有投资价值。换手率过高（>15%）反而可能是主力出货的信号，需要警惕。
2. **"换手率可以直接跨板块比较"** — 不同板块的换手率天然不同：小盘股换手率通常高于大盘股，次新股通常高于老股。应该与同板块或自身历史数据进行比较。
3. **"流通股本是固定的"** — 流通股本会变化：大股东解禁、增发、回购等都会改变流通股本，从而影响换手率计算。使用时需要注意流通股本的更新。
