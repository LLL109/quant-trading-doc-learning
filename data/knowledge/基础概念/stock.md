# 股票

> 股票是股份公司发行的所有权凭证，持有股票即拥有公司相应比例的所有权。

## 定义

股票（Stock）是股份有限公司为筹集资金而发行给股东的有价证券，代表股东对公司的所有权。每股股票代表股东对企业拥有一个基本单位的所有权。持有股票的股东享有分红权、投票权等权利，同时也承担公司经营风险。

对程序员来说，可以把股票理解为一个"分布式系统中的权益令牌"——你持有一个token，就拥有对应比例的系统权益。

## 核心内容

### 股份公司与上市

股份公司通过IPO（首次公开募股）在证券交易所上市，向公众发行股票。上市后，股票可以在二级市场自由买卖。

- **一级市场**：公司首次发行股票，投资者从公司手中直接购买（类似产品的"首发"）
- **二级市场**：投资者之间互相买卖已发行的股票（类似"二手市场"，但价格实时变动）

### A股特点

A股是在中国大陆上市、以人民币计价的股票，主要有以下特点：

| 特点 | 说明 |
|------|------|
| 交易制度 | T+1（今天买，明天才能卖） |
| 涨跌停限制 | 主板10%，科创板/创业板20%，北交所30% |
| 交易时间 | 9:30-11:30, 13:00-15:00 |
| 最小交易单位 | 100股（1手） |
| 结算货币 | 人民币 |

### 股票分类

按板块分：
- **主板**（沪市600/601/603/605开头，深市000/001开头）：大型成熟企业，涨跌停10%
- **科创板**（688开头）：科技创新企业，涨跌停20%，上市前5个交易日不设涨跌幅
- **创业板**（300/301开头）：成长型创新企业，涨跌停20%
- **北交所**（8开头）：中小创新企业，涨跌停30%

### 举例说明

假设某公司总股本1亿股，你买入10000股：
- 你拥有该公司 10000/100000000 = 0.01% 的所有权
- 如果股价从10元涨到11元，你的持仓市值从10万元变为11万元，盈利1万元
- 但由于T+1制度，你今天无法卖出，明天才能卖出

## 计算公式

**持仓市值：**
$$\text{市值} = \text{持股数量} \times \text{当前股价}$$

**单笔交易盈亏：**
$$\text{盈亏} = \text{卖出价} \times \text{数量} - \text{买入价} \times \text{数量} - \text{手续费}$$

**涨跌幅：**
$$\text{涨跌幅} = \frac{\text{当前价} - \text{昨收价}}{\text{昨收价}} \times 100\%$$

## Python 代码

```python
import akshare as ak
import pandas as pd

# 获取单只股票的历史行情（以贵州茅台为例）
df = ak.stock_zh_a_hist(symbol="600519", period="daily",
                         start_date="20240101", end_date="20240131",
                         adjust="qfq")
print(df.columns.tolist())
# ['日期', '开盘', '收盘', '最高', '最低', '成交量', '成交额', '振幅', '涨跌幅', '涨跌额', '换手率']

# 计算日收益率
df['日收益率'] = df['收盘'].pct_change()

# 计算持仓盈亏：假设在第一个交易日买入100股
initial_price = df['收盘'].iloc[0]
shares = 100
df['持仓市值'] = df['收盘'] * shares
df['浮动盈亏'] = df['持仓市值'] - initial_price * shares
print(f"买入价: {initial_price:.2f}, 最终盈亏: {df['浮动盈亏'].iloc[-1]:.2f}元")
```

## 常见误区

1. **"股票便宜所以值得买"** — 股价高低与投资价值无直接关系。100元的股票可能被低估，2元的股票可能被高估。关键看公司基本面和估值，而非绝对价格。
2. **"T+0和T+1只是时间差异"** — T+1制度深刻影响交易策略。日内买入后无法止损，意味着风险控制必须在买入前完成，这对量化策略设计有重大影响。
3. **"涨跌停就是最多涨/跌10%"** — 实际上不同板块涨跌停幅度不同：科创板/创业板为20%，北交所为30%，新股上市首日（部分板块）不设涨跌停。
