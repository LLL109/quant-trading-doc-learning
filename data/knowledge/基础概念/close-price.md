# 收盘价

> 收盘价是一天交易的终点，是技术分析和结算中最被重视的价格。

## 定义

收盘价（Close Price）是指证券在每个交易日最后一笔成交的价格。在A股中，深市通过收盘集合竞价（14:57-15:00）确定收盘价，沪市则取最后一笔成交价（近年来也逐步引入收盘集合竞价机制）。

收盘价之所以重要，是因为它代表了当天市场经过全天博弈后对资产价值的最终定价，是多数技术指标和结算体系的基准价格。

## 核心内容

### 为什么收盘价最重要

1. **结算基准**：融资融券、质押回购等业务的盯市基准
2. **技术分析基础**：几乎所有技术指标（MA、MACD、RSI等）都基于收盘价计算
3. **基金估值**：基金持仓的公允价值以收盘价计量
4. **涨跌幅计算**：次日涨跌幅的基准是前一日收盘价

### 收盘集合竞价

深市在14:57-15:00进行收盘集合竞价：
- 14:57之前是连续竞价
- 14:57进入收盘集合竞价，不能撤单
- 15:00确定收盘价并撮合成交

沪市的收盘价产生方式经历了多次改革，目前部分采用类似深市的收盘集合竞价机制。

### 收盘价与日内走势

收盘价相对于开盘价和日内最高最低价的位置，反映了多空力量的最终对比：

| 情况 | K线形态 | 含义 |
|------|--------|------|
| 收盘价接近日内最高价 | 长上影线短或无 | 多方占优，次日可能继续上涨 |
| 收盘价接近日内最低价 | 长下影线短或无 | 空方占优，次日可能继续下跌 |
| 收盘价接近开盘价 | 十字星 | 多空平衡，方向不确定 |
| 收盘价在日内中间位置 | 有上下影线 | 多空争夺激烈 |

### 常见的收盘策略

1. **尾盘策略**：在最后30分钟（14:30-15:00）根据日内走势决定是否持仓过夜
2. **收盘突破策略**：价格收盘突破关键阻力位/支撑位时入场
3. **日内交易平仓**：日内交易者通常在收盘前平仓，避免隔夜风险

### 举例说明

某股票当日走势：
- 开盘10.00元，盘中最高10.50元，最低9.80元
- 情况A：收盘10.45元（接近日内最高）
  - K线为大阳线，上影线极短
  - 说明多方力量强劲，次日高开概率大
- 情况B：收盘9.85元（接近日内最低）
  - K线为大阴线，下影线极短
  - 说明空方占优，次日可能继续下跌
- 情况C：收盘10.05元（接近开盘价）
  - K线为十字星
  - 多空平衡，方向需进一步观察

## 计算公式

**收盘价相对位置：**
$$\text{收盘位置} = \frac{\text{收盘价} - \text{最低价}}{\text{最高价} - \text{最低价}}$$

- 收盘位置接近1：收盘价接近日内最高
- 收盘位置接近0：收盘价接近日内最低
- 收盘位置接近0.5：收盘价在日内中间

**涨跌幅：**
$$\text{涨跌幅} = \frac{\text{今日收盘价} - \text{昨日收盘价}}{\text{昨日收盘价}} \times 100\%$$

## Python 代码

```python
import akshare as ak
import pandas as pd

# 获取股票日K线
df = ak.stock_zh_a_hist(symbol="600519", period="daily",
                         start_date="20240101", end_date="20240630",
                         adjust="qfq")

# 计算收盘价在日内区间的位置
df['收盘位置'] = (df['收盘'] - df['最低']) / (df['最高'] - df['最低'])

# 分析收盘位置的分布
print("收盘位置统计:")
print(df['收盘位置'].describe())

# 收盘位置与次日涨跌的关系
df['次日涨跌'] = df['收盘'].pct_change().shift(-1)
df['收盘类型'] = pd.cut(df['收盘位置'], bins=[0, 0.3, 0.7, 1.0],
                        labels=['低位收盘', '中间收盘', '高位收盘'])
print("\n收盘位置与次日涨跌:")
print(df.groupby('收盘类型')['次日涨跌'].mean())

# 收盘突破策略示例
df['MA20'] = df['收盘'].rolling(20).mean()
df['突破信号'] = (df['收盘'] > df['MA20']) & (df['收盘'].shift(1) <= df['MA20'].shift(1))
print(f"\n20日均线突破次数: {df['突破信号'].sum()}")
```

## 常见误区

1. **"收盘价就是最后一笔成交价"** — 在有收盘集合竞价的市场中（如深市），收盘价是收盘集合竞价确定的价格，不一定是15:00的那一笔成交价。
2. **"收盘价一定在最高价和最低价之间"** — 这是正确的，收盘价一定在当日最高价和最低价之间（包含端点）。但开盘价也可能等于最高价或最低价（如一字涨停/跌停）。
3. **"收盘价涨了就是强势"** — 收盘价虽然高于昨收价（涨），但如果盘中冲高回落，收盘位置在日内低位，实际表现是"冲高回落"，说明上方抛压大，可能不是真正的强势。
