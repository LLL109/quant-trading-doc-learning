# 成交量

> 成交量是市场活跃度的最直接度量，量是价的先行指标。

## 定义

成交量（Volume）是指在一定时间内某只股票或整个市场成交的股票数量。在A股中，成交量通常以"手"为单位（1手=100股）。成交量反映了市场参与者的交易意愿和资金的流入流出情况。

对程序员来说，成交量就像一个系统的"请求量/QPS"——它告诉你有多少用户在活跃地使用这个系统。

## 核心内容

### 成交量的意义

成交量是除价格之外最重要的市场数据：

1. **反映市场热度**：成交量大说明参与交易的人多，市场关注度高
2. **验证价格走势**：价格上涨需要成交量的配合才可靠
3. **预示趋势变化**：量在价先，成交量的变化往往先于价格变化
4. **衡量流动性**：成交量大的股票容易买卖，冲击成本低

### 量价关系

"量价配合"是技术分析的核心原则：

| 价格走势 | 成交量变化 | 含义 | 可靠性 |
|---------|-----------|------|--------|
| 上涨 | 放量 | 多方有力推动，趋势健康 | 高 |
| 上涨 | 缩量 | 上涨动力不足，可能见顶 | 低 |
| 下跌 | 放量 | 恐慌性抛售，可能加速下跌 | 高 |
| 下跌 | 缩量 | 抛压减轻，可能见底 | 中 |
| 横盘 | 放量 | 蓄势待变，可能突破 | 高 |
| 横盘 | 缩量 | 观望气氛浓，方向不明 | 低 |

### 放量与缩量

**放量**：成交量显著高于近期平均水平（通常2倍以上）
- 可能原因：重大消息、主力资金介入、突破关键价位
- 含义：市场分歧加大，买卖双方都积极交易

**缩量**：成交量显著低于近期平均水平
- 可能原因：无重大消息、投资者观望、假期效应
- 含义：市场参与度低，价格变动可能不大

**天量**：成交量创出历史或近期新高
- 常说"天量见天价"——成交量极大时，往往是阶段性顶部

**地量**：成交量创出历史或近期新低
- 常说"地量见地价"——成交量极小时，往往是阶段性底部

### 举例说明

某股票近期走势：
- 过去20日平均成交量 = 1000万手
- 今日成交量 = 3000万手（放量3倍），价格上涨5%
- 解读：放量上涨，多方力量强劲，上涨趋势健康

另一种情况：
- 过去20日平均成交量 = 1000万手
- 今日成交量 = 3000万手，但价格下跌5%
- 解读：放量下跌，恐慌性抛售，可能还有进一步下跌空间

## 计算公式

**成交量：**
$$\text{成交量} = \sum_{i=1}^{n} \text{第i笔交易的成交股数}$$

**成交额：**
$$\text{成交额} = \sum_{i=1}^{n} (\text{第i笔成交价} \times \text{第i笔成交量})$$

**量比：**
$$\text{量比} = \frac{\text{当日成交量}}{\text{过去5日平均成交量}}$$

**平均成交量：**
$$\text{MA\_Vol}_N = \frac{1}{N} \sum_{i=1}^{N} \text{Vol}_i$$

                         start_date="20240101", end_date="20240630",
                         adjust="qfq")

# 计算成交量均线
df['Vol_MA5'] = df['成交量'].rolling(5).mean()
df['Vol_MA20'] = df['成交量'].rolling(20).mean()

# 计算量比
df['量比'] = df['成交量'] / df['Vol_MA5']

# 识别放量和缩量
df['量状态'] = '正常'
df.loc[df['量比'] > 2.0, '量状态'] = '放量'
df.loc[df['量比'] < 0.5, '量状态'] = '缩量'

print("成交量状态统计:")
print(df['量状态'].value_counts())

# 量价关系分析
df['价格涨跌'] = df['收盘'].pct_change()

## 常见误区

1. **"成交量大就是好事"** — 成交量大只说明交易活跃，并不意味着价格一定涨。放量下跌同样是放量，但意味着恐慌性抛售。需要结合价格走势判断。
2. **"成交量可以直接跨股票比较"** — 不同股票的股本不同，成交量的绝对值无法直接比较。应该使用换手率（成交量/流通股本）来进行跨股票比较。
3. **"成交量数据都是真实的"** — A股存在"对倒"行为（主力自买自卖制造虚假成交量），特别是在小盘股中。通过观察成交明细和分时成交可以识别这种行为。
