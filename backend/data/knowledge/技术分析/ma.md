# 均线

> 均线是将过去 N 个交易日的收盘价做平均，得到一条平滑曲线，用来判断价格趋势方向。

## 定义

移动平均线（Moving Average，简称 MA 或均线）是最基础的技术分析指标。它的核心思想很简单：把最近 N 天的收盘价取平均值，画成一条线。因为每天都会丢掉最老一天、加入最新一天的数据，所以叫"移动"平均。

对程序员来说，均线就是一个**滑动窗口平均值**（sliding window average），窗口大小就是周期 N。

## 核心内容

### 常用周期

不同周期的均线反映不同时间尺度的趋势：

| 周期 | 名称 | 含义 | 典型用途 |
|------|------|------|----------|
| 5日 | 周线 | 一周交易日平均 | 短线交易 |
| 10日 | 双周线 | 两周平均 | 短线交易 |
| 20日 | 月线 | 一个月平均 | 中短线 |
| 60日 | 季线 | 一个季度平均 | 中线趋势 |
| 120日 | 半年线 | 半年平均 | 中长线 |
| 250日 | 年线 | 一年平均（约250个交易日） | 牛熊分界 |

### SMA vs EMA

均线有两种主要计算方式：

- **SMA（简单移动平均）**：每个价格权重相等，算术平均
- **EMA（指数移动平均）**：近期价格权重更大，对最新价格变化反应更快

选择建议：
- 信号敏感度要求高 → 用 EMA
- 需要平滑过滤噪音 → 用 SMA
- 入门阶段建议先理解 SMA，再学 EMA

### 趋势判断

- **价格在均线之上** → 偏多（上升趋势）
- **价格在均线之下** → 偏空（下降趋势）
- **均线向上倾斜** → 趋势向上
- **均线向下倾斜** → 趋势向下
- **多条均线粘合** → 震荡整理，可能即将选择方向

### 均线的支撑与阻力

在上升趋势中，均线经常充当"支撑位"——价格回调到均线附近就反弹。在下降趋势中，均线充当"阻力位"——价格反弹到均线附近就回落。

这是因为很多交易者都在关注同一条均线，当价格接近时会集中行动，形成自我实现的预言。

## 计算公式

### SMA（简单移动平均）

$$SMA_N = \frac{1}{N}\sum_{i=0}^{N-1}P_{t-i}$$

其中 $P_t$ 是第 $t$ 天的收盘价，$N$ 是周期。

### EMA（指数移动平均）

$$EMA_t = \alpha \cdot P_t + (1-\alpha) \cdot EMA_{t-1}$$

其中 $\alpha = \frac{2}{N+1}$ 是平滑系数。

## Python 代码

```python
import pandas as pd

# 假设 df 有 'close' 列，索引是日期
# 计算 SMA
df['sma_20'] = df['close'].rolling(window=20).mean()

# 计算 EMA
df['ema_20'] = df['close'].ewm(span=20, adjust=False).mean()

# 一次性计算多个周期
for n in [5, 10, 20, 60, 120, 250]:
    df[f'ma_{n}'] = df['close'].rolling(window=n).mean()

# 趋势判断示例
df['trend'] = 'neutral'
df.loc[df['close'] > df['ma_60'], 'trend'] = 'bullish'
df.loc[df['close'] < df['ma_60'], 'trend'] = 'bearish'
```

## 常见误区

1. **均线是"预测指标"** — 均线本质是滞后指标，它描述的是过去 N 天的平均成本，不是预测未来。股价先动，均线后跟。
2. **均线金叉就是买入信号** — 金叉在趋势行情中有效，但在震荡行情中会反复出现假信号，导致频繁止损。需要结合成交量和市场环境判断。
3. **周期越长越准确** — 长周期均线信号更可靠但更滞后，短周期更灵敏但噪音更多。没有"最优"周期，取决于你的交易风格。
4. **只看一条均线就够了** — 单条均线只能告诉你趋势方向，多条均线配合可以判断趋势强度和可能的转折点。

## 相关概念

- [SMA](/k/sma) — 简单移动平均线的详细计算
- [EMA](/k/ema) — 指数移动平均线，对近期更敏感
- [金叉](/k/golden-cross) — 短期均线上穿长期均线的买入信号
- [死叉](/k/death-cross) — 短期均线下穿长期均线的卖出信号
- [MACD](/k/macd) — 基于 EMA 差值构建的更复杂指标
