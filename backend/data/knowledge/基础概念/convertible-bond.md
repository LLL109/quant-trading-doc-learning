# 可转债

> 可转债是"债券+股票看涨期权"的组合，下有保底（债性），上不封顶（股性）。

## 定义

可转换债券（Convertible Bond）是一种可以在特定条件下转换为发行公司股票的债券。持有人可以选择持有到期收取本息，也可以在转股期内按照约定价格将债券转换为公司股票。

对程序员来说，可转债就像一个"带有if-else逻辑的金融产品"：if 股价涨得好，转股赚大钱；else 持有到期，至少保本收息。

## 核心内容

### 核心概念

| 概念 | 定义 | 举例 |
|------|------|------|
| 面值 | 可转债的票面价值 | 100元 |
| 票面利率 | 债券利息，通常很低 | 第一年0.3%，逐年递增 |
| 转股价 | 转换成股票的价格 | 10元/股 |
| 转股比例 | 每张可转债能转多少股 | 100/10 = 10股 |
| 转股价值 | 转股后的市场价值 | 正股价 x 转股比例 |
| 转股溢价率 | 转债价格相对转股价值的溢价 | (转债价格-转股价值)/转股价值 |
| 到期日 | 可转债到期还本付息的日期 | 通常6年 |

### 债性与股性

**债性**（保底特性）：
- 持有到期可以获得本金和利息
- 即使正股暴跌，可转债价格也不会无限下跌（有债底保护）
- 到期赎回价通常在106-115元之间

**股性**（上行空间）：
- 当正股价 > 转股价时，可转债跟随正股上涨
- 转股溢价率低的可转债，股性更强
- 理论上不封顶，涨多高取决于正股

### T+0交易

A股可转债实行T+0交易制度，即当天买入可以当天卖出。这是与股票（T+1）最大的区别。

T+0的特点：
- 可以日内反复买卖
- 适合短线交易和日内策略
- 不设涨跌停（2022年8月后有20%/30%临时停牌机制）

### 强制赎回（强赎）

当正股价持续高于转股价的130%时，发行公司有权以略高于面值的价格强制赎回。这实际上是在"逼迫"投资者转股——因为转股比被低价赎回更划算。

触发条件：正股价连续30个交易日中至少15个交易日不低于转股价的130%。

### 回售条款

当正股价持续低于转股价的70%时，投资者有权以面值加利息的价格将可转债回售给公司。这是对投资者的保护。

### 举例说明

某可转债：面值100元，转股价10元
- 正股价8元时：转股价值 = 8 x 10 = 80元，没人愿意转股（亏了20元）
- 正股价10元时：转股价值 = 10 x 10 = 100元，转股刚好不亏不赚
- 正股价13元时：转股价值 = 13 x 10 = 130元，转股赚30%

如果可转债市场价格125元，转股溢价率 = (125-130)/130 = -3.8%（折价），存在套利空间。

## 计算公式

**转股比例：**
$$\text{转股比例} = \frac{\text{可转债面值}}{\text{转股价}}$$

**转股价值：**
$$\text{转股价值} = \text{正股价} \times \text{转股比例} = \text{正股价} \times \frac{100}{\text{转股价}}$$

**转股溢价率：**
$$\text{转股溢价率} = \frac{\text{可转债价格} - \text{转股价值}}{\text{转股价值}} \times 100\%$$

**纯债价值**（用现金流折现）：
$$\text{纯债价值} = \sum_{t=1}^{n} \frac{C_t}{(1+r)^t} + \frac{\text{到期赎回价}}{(1+r)^n}$$

## Python 代码

```python
import akshare as ak
import pandas as pd

# 获取可转债列表
cb_list = ak.bond_cb_jsl()
print(cb_list[['转债名称', '转债代码', '现价', '正股名称', '正股价', '转股价', '转股溢价率']].head(10))

# 计算转股价值和溢价率
def calc_conversion_value(stock_price, conversion_price):
    """计算转股价值"""
    ratio = 100 / conversion_price
    value = stock_price * ratio
    return value, ratio

def calc_premium_rate(cb_price, conversion_value):
    """计算转股溢价率"""
    return (cb_price - conversion_value) / conversion_value

# 示例
stock_price = 12.5  # 正股价
conversion_price = 10.0  # 转股价
cb_price = 118.0  # 可转债现价

conv_value, ratio = calc_conversion_value(stock_price, conversion_price)
premium = calc_premium_rate(cb_price, conv_value)
print(f"转股比例: {ratio:.1f}股/张")
print(f"转股价值: {conv_value:.2f}元")
print(f"转股溢价率: {premium:.2%}")

# 筛选低溢价率的可转债（量化策略示例）
# 假设已获取cb_list数据
cb_list['转股溢价率_num'] = pd.to_numeric(cb_list['转股溢价率'].str.rstrip('%'), errors='coerce') / 100
low_premium = cb_list[cb_list['转股溢价率_num'] < 0.05].sort_values('转股溢价率_num')
print("低溢价率可转债:")
print(low_premium[['转债名称', '现价', '转股溢价率']].head())
```

## 常见误区

1. **"可转债就是保本的"** — 虽然可转债有债底保护，但如果你以高于到期赎回价的价格买入，且公司不强赎、正股又暴跌，持有到期也可能亏损。此外，如果发行公司违约（信用风险），本金也可能损失。
2. **"可转债和股票一样有涨跌停"** — 可转债的涨跌停规则与股票不同。2022年8月后，上交所和深交所对可转债设置了临时停牌机制（涨跌20%/30%停牌），但没有像股票那样的10%硬涨跌停限制。
3. **"转股溢价率越低越好"** — 低溢价率意味着转债跟随正股波动更紧密，但也意味着失去了债底保护。高溢价率转债虽然上行空间小，但下跌时更有安全垫。
