# 期货

> 期货是一种标准化的远期合约，约定在未来某个时间以特定价格买卖某种资产。

## 定义

期货（Futures）是由期货交易所统一制定的、规定在将来某一特定时间和地点交割一定数量标的物的标准化合约。期货合约的买方有义务在到期日按约定价格买入标的物，卖方有义务卖出。

对程序员来说，期货合约就像一个"带有时间戳和参数约束的API调用承诺"——你提前锁定了价格和数量，到期必须执行。

## 核心内容

### 保证金与杠杆

期货交易采用保证金制度，不需要支付合约的全部金额，只需缴纳一定比例的保证金即可交易：

- **保证金比例**：通常为合约价值的5%-20%
- **杠杆倍数**：1 / 保证金比例

| 保证金比例 | 杠杆倍数 | 含义 |
|-----------|---------|------|
| 10% | 10倍 | 用1万元可以控制10万元的合约 |
| 20% | 5倍 | 用2万元可以控制10万元的合约 |

杠杆是双刃剑：盈利和亏损都被放大。10倍杠杆意味着标的物价格波动1%，你的保证金盈亏就是10%。

### 多空机制

- **做多（买入开仓）**：预期价格上涨，先买后卖
- **做空（卖出开仓）**：预期价格下跌，先卖后买

期货天然支持做空，这是与股票最大的区别之一。做空不需要借券，直接卖出开仓即可。

### 合约规格

每个期货合约都有标准化的规格：

| 要素 | 说明 | 示例（沪深300股指期货） |
|------|------|----------------------|
| 合约代码 | 唯一标识 | IF2401（2024年1月到期） |
| 标的物 | 合约对应的基础资产 | 沪深300指数 |
| 合约乘数 | 每点对应的金额 | 300元/点 |
| 最小变动价位 | 价格最小变动单位 | 0.2点 |
| 保证金比例 | 交易所规定的最低保证金 | 12% |
| 交割月份 | 合约到期月份 | 当月、下月、随后两个季月 |
| 最后交易日 | 合约最后交易日期 | 到月第三个周五 |

### 移仓换月

期货合约有到期日，如果不想交割实物或现金，需要在到期前将持仓转移到下一月份的合约，这叫"移仓换月"。

移仓换月的成本取决于近月和远月合约的价差（升贴水），这对量化策略的长期持有成本有重要影响。

### 强制平仓（强平）

当保证金不足时，交易所或期货公司会强制平仓：
- **维持保证金**：持仓期间需维持的最低保证金水平
- 当账户可用资金 < 0 时，会收到追加保证金通知（margin call）
- 如果未及时补足，将被强制平仓

### 举例说明

假设交易沪深300股指期货（IF）：
- 当前沪深300指数 = 4000点
- 合约乘数 = 300元/点
- 合约价值 = 4000 x 300 = 120万元
- 保证金比例 = 12%
- 需要保证金 = 120万 x 12% = 14.4万元

如果你做多1手IF，指数上涨1%到4040点：
- 盈利 = (4040 - 4000) x 300 = 12000元
- 收益率 = 12000 / 144000 = 8.33%（杠杆放大了1%的涨幅到8.33%）

如果指数下跌5%到3800点：
- 亏损 = (4000 - 3800) x 300 = 60000元
- 亏损率 = 60000 / 144000 = 41.67%（杠杆放大了5%的跌幅到41.67%）

## 计算公式

**合约价值：**
$$\text{合约价值} = \text{期货价格} \times \text{合约乘数} \times \text{手数}$$

**保证金：**
$$\text{保证金} = \text{合约价值} \times \text{保证金比例}$$

**杠杆倍数：**
$$\text{杠杆倍数} = \frac{1}{\text{保证金比例}}$$

**盈亏计算：**
$$\text{盈亏} = (\text{卖出价} - \text{买入价}) \times \text{合约乘数} \times \text{手数}$$

## Python 代码

```python
import akshare as ak
import pandas as pd

# 获取期货列表
futures_list = ak.futures_display_main_sina()
print(futures_list.head())

# 获取某个期货品种的行情
df = ak.futures_zh_daily_sina(symbol="IF0")  # 沪深300股指期货主力合约
print(df.tail())

# 计算保证金和杠杆
def calc_margin(contract_price, multiplier, lots, margin_ratio):
    """计算所需保证金"""
    contract_value = contract_price * multiplier * lots
    margin = contract_value * margin_ratio
    leverage = 1 / margin_ratio
    return contract_value, margin, leverage

# 示例：沪深300股指期货
price = 4000  # 指数点位
multiplier = 300  # 合约乘数
lots = 1
margin_ratio = 0.12

contract_value, margin, leverage = calc_margin(price, multiplier, lots, margin_ratio)
print(f"合约价值: {contract_value:,.0f}元")
print(f"所需保证金: {margin:,.0f}元")
print(f"杠杆倍数: {leverage:.1f}倍")

# 计算盈亏
def calc_pnl(entry_price, exit_price, multiplier, lots, direction='long'):
    """计算期货盈亏"""
    if direction == 'long':
        pnl = (exit_price - entry_price) * multiplier * lots
    else:
        pnl = (entry_price - exit_price) * multiplier * lots
    return pnl

# 做多1手，从4000涨到4040
pnl = calc_pnl(4000, 4040, 300, 1, 'long')
margin_used = 4000 * 300 * 0.12
print(f"盈亏: {pnl:,.0f}元, 收益率: {pnl/margin_used:.2%}")
```

## 常见误区

1. **"期货风险只是股票风险的放大版"** — 期货除了价格风险外，还有到期交割风险、保证金追加风险、流动性风险。而且杠杆放大不仅放大收益，亏损可能超过本金（穿仓）。
2. **"期货可以一直持有"** — 期货合约有到期日，到期后必须交割或平仓。长期持有需要不断移仓换月，每次移仓都有成本。
3. **"保证金就是全部成本"** — 保证金只是履约担保，不是购买成本。期货交易还需要支付手续费，而且盈亏是每日结算（逐日盯市），盈利可以取出但亏损需要立即补充。
