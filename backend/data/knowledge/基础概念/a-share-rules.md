# A股交易规则

> A股交易有一套严格的"游戏规则"，理解这些规则是设计量化策略的基础前提。

## 定义

A股交易规则是由中国证监会和各交易所制定的，规范股票买卖行为的制度体系。包括交易时间、交易方式、涨跌停限制、交割制度等。这些规则直接决定了量化策略的设计空间和约束条件。

## 核心内容

### 交易时间

| 时间段 | 活动 | 说明 |
|--------|------|------|
| 9:15-9:20 | 开盘集合竞价 | 可以下单、撤单 |
| 9:20-9:25 | 开盘集合竞价 | 只能下单，不能撤单 |
| 9:25-9:30 | 静默期 | 交易所处理数据，不接受申报 |
| 9:30-11:30 | 上午连续竞价 | 正常交易 |
| 13:00-14:57 | 下午连续竞价 | 正常交易 |
| 14:57-15:00 | 收盘集合竞价（深市） | 确定收盘价 |
| 15:00 | 收盘 | 交易结束 |

### T+1 交易制度

T+1是A股最核心的交易制度之一：
- **T日买入**的股票，最早在**T+1日**（即下一个交易日）才能卖出
- 卖出股票获得的资金，**当日可用于买入**其他股票，但**T+1日才能提现**

对量化策略的影响：
- 无法日内止损，风险控制必须前置
- 隔夜持仓承担"跳空"风险（次日开盘价可能大幅偏离前收盘价）
- 日内T+0无法直接实现，但可以通过"底仓+日内做T"间接实现

### 涨跌停制度

| 板块 | 涨跌停幅度 | 特殊规则 |
|------|-----------|---------|
| 主板（沪深） | ±10% | ST股为±5% |
| 科创板 | ±20% | 上市前5日不设涨跌幅 |
| 创业板 | ±20% | 上市前5日不设涨跌幅 |
| 北交所 | ±30% | 上市首日不设涨跌幅 |

涨跌停价计算：$\text{涨停价} = \text{昨收价} \times (1 + \text{涨停幅度})$，结果四舍五入到分。

### 最小交易单位

- **买入**：最少100股（1手），必须是100股的整数倍
- **卖出**：可以不是100的整数倍（比如持有235股，可以全部卖出235股）
- 例外：科创板最低买入200股，但超过200股后可以按1股递增

### 停牌与复牌

停牌是交易所暂停某只股票的交易，常见原因：
- 重大资产重组
- 重大信息披露
- 股价异常波动
- 违规调查

停牌期间无法买卖，这对量化策略的流动性管理有重要影响。

### 举例说明

假设你有10万元资金：
- **周一9:35**：以10元/股买入某股票5000股（花费5万元）
- **周一14:00**：该股涨到10.5元，你想卖出获利——**无法卖出**（T+1限制）
- **周二9:30**：现在可以卖出了，但开盘价跌到10.2元——你承受了隔夜风险
- **周二9:35**：以10.2元卖出，盈利 = (10.2 - 10) × 5000 = 1000元
- 资金要到**周三**才能提现

## 计算公式

**涨跌停价格：**
$$\text{涨停价} = \text{round}(\text{昨收价} \times 1.10, 2)$$
$$\text{跌停价} = \text{round}(\text{昨收价} \times 0.90, 2)$$

**最小买入金额：**
$$\text{最小买入金额} = 100 \times \text{股价}$$

**交易费用：**
$$\text{总费用} = \text{佣金} + \text{印花税} + \text{过户费}$$
- 佣金：成交金额的万分之2.5左右（最低5元）
- 印花税：卖出时收取成交金额的千分之1（2023年减半后）
- 过户费：成交金额的万分之0.1

## Python 代码

```python
import math
import pandas as pd
import akshare as ak

def calc_limit_price(prev_close, limit_pct=0.10):
    """计算涨跌停价格"""
    limit_up = round(prev_close * (1 + limit_pct), 2)
    limit_down = round(prev_close * (1 - limit_pct), 2)
    return limit_up, limit_down

# 示例：贵州茅台
prev_close = 1680.00
up, down = calc_limit_price(prev_close, 0.10)
print(f"昨收: {prev_close}, 涨停: {up}, 跌停: {down}")

def calc_trading_cost(amount, direction='buy', commission_rate=0.00025):
    """计算交易费用"""
    commission = max(amount * commission_rate, 5)  # 佣金最低5元
    stamp_tax = amount * 0.001 if direction == 'sell' else 0  # 印花税仅卖出
    transfer_fee = amount * 0.00001  # 过户费
    return commission + stamp_tax + transfer_fee

# 计算买卖一次的总费用
buy_amount = 10 * 5000  # 10元 x 5000股
buy_cost = calc_trading_cost(buy_amount, 'buy')
sell_cost = calc_trading_cost(buy_amount, 'sell')
print(f"买入费用: {buy_cost:.2f}元, 卖出费用: {sell_cost:.2f}元")
print(f"一买一卖总费用: {buy_cost + sell_cost:.2f}元")

# 检查某日是否涨跌停
df = ak.stock_zh_a_hist(symbol="600519", period="daily",
                         start_date="20240101", end_date="20241231",
                         adjust="qfq")
df['涨停'] = df['涨跌幅'] >= 9.9
df['跌停'] = df['涨跌幅'] <= -9.9
print(f"涨停天数: {df['涨停'].sum()}, 跌停天数: {df['跌停'].sum()}")
```

## 常见误区

1. **"T+1意味着今天买明天必须卖"** — T+1只限制了卖出的最早时间，不是说必须在第二天卖出。你可以持有任意长时间，只是不能当天买当天卖。
2. **"涨跌停是绝对不能超过的"** — 实际上，涨停后仍可能有成交（卖单以涨停价挂出），跌停同理。涨跌停只是限制了报价范围，不限制成交。
3. **"所有股票的涨跌停幅度都是10%"** — 科创板和创业板是20%，北交所是30%，ST股是5%，新股上市首日（部分板块）不设涨跌停限制。
