# 波动率

> 波动率是收益率的离散程度，是量化交易中衡量风险的核心指标。

## 定义

波动率（Volatility）是衡量资产价格或收益率波动剧烈程度的统计指标，通常用收益率的标准差来表示。波动率越大，说明价格变化越剧烈，不确定性越高，风险越大。

对程序员来说，波动率就像一个系统的"响应时间标准差"——平均响应时间可能很快，但如果标准差很大，说明系统不稳定，有时候快有时候慢。

## 核心内容

### 为什么波动率等于风险

在现代金融理论中，波动率被用作风险的代理变量：
- 高波动率 = 价格不确定性高 = 未来可能的损失范围大
- 低波动率 = 价格相对稳定 = 未来可能的损失范围小

虽然波动率不完全等同于风险（它没有区分上行波动和下行波动），但由于其简洁和可计算性，仍然是使用最广泛的风险度量指标。

### 历史波动率的计算

**步骤：**
1. 计算日收益率序列 $R_1, R_2, ..., R_n$
2. 计算日收益率的标准差 $\sigma_{\text{日}}$
3. 年化：$\sigma_{\text{年化}} = \sigma_{\text{日}} \times \sqrt{252}$

**为什么乘以 $\sqrt{252}$？**
- 假设日收益率独立同分布
- 方差具有可加性：年方差 = 日方差 x 252
- 标准差 = $\sqrt{\text{方差}}$，所以年标准差 = 日标准差 x $\sqrt{252}$

### 不同类型的波动率

| 类型 | 定义 | 用途 |
|------|------|------|
| 历史波动率 | 基于历史收益率计算 | 衡量过去的波动情况 |
| 隐含波动率 | 从期权价格反推 | 衡量市场对未来的预期 |
| 已实现波动率 | 基于高频数据计算 | 更精确的历史波动度量 |

### 波动率的解读

| 年化波动率 | 资产类型 | 含义 |
|-----------|---------|------|
| < 5% | 货币基金、国债 | 极低风险 |
| 5%-15% | 债券基金、大盘蓝筹 | 低风险 |
| 15%-25% | 指数基金、大型股票 | 中等风险 |
| 25%-40% | 成长股、行业ETF | 高风险 |
| > 40% | 期权、加密货币 | 极高风险 |

### 举例说明

某股票过去30天的日收益率标准差为2%：
- 年化波动率 = 2% x √252 = 31.7%
- 含义：该股票的年收益率大约有68%的概率落在 ±31.7% 的范围内（假设正态分布）
- 即：如果当前股价100元，一年后大约有68%的概率在68.3元到131.7元之间

另一种理解：
- 日波动率2%，意味着每天的价格变动大约在 ±2% 范围内
- 如果股价100元，每天大概率波动 ±2元

## 计算公式

**日波动率：**
$$\sigma_{\text{日}} = \sqrt{\frac{1}{N-1} \sum_{t=1}^{N}(R_t - \bar{R})^2}$$

**年化波动率：**
$$\sigma_{\text{年化}} = \sigma_{\text{日}} \times \sqrt{252}$$

**滚动波动率（20日）：**
$$\sigma_{20,t} = \sqrt{\frac{1}{19} \sum_{i=t-19}^{t}(R_i - \bar{R}_{20})^2}$$

**Parkinson波动率估计（用最高最低价）：**
$$\sigma_P = \sqrt{\frac{1}{4N\ln2} \sum_{t=1}^{N}\left(\ln\frac{H_t}{L_t}\right)^2}$$

## Python 代码

```python
import akshare as ak
import pandas as pd
import numpy as np

# 获取股票数据
df = ak.stock_zh_a_hist(symbol="600519", period="daily",
                         start_date="20230101", end_date="20240630",
                         adjust="qfq")

# 计算日收益率
df['日收益率'] = df['收盘'].pct_change()

# 计算整体历史波动率
daily_vol = df['日收益率'].std()
annual_vol = daily_vol * np.sqrt(252)
print(f"日波动率: {daily_vol:.4%}")
print(f"年化波动率: {annual_vol:.2%}")

# 计算滚动波动率
df['波动率_20日'] = df['日收益率'].rolling(20).std() * np.sqrt(252)
df['波动率_60日'] = df['日收益率'].rolling(60).std() * np.sqrt(252)

print(f"\n20日滚动波动率最新值: {df['波动率_20日'].iloc[-1]:.2%}")
print(f"60日滚动波动率最新值: {df['波动率_60日'].iloc[-1]:.2%}")

# Parkinson波动率估计（利用最高最低价）
df['HL_ratio'] = np.log(df['最高'] / df['最低'])
parkinson_vol = np.sqrt((df['HL_ratio']**2).mean() / (4 * np.log(2))) * np.sqrt(252)
print(f"\nParkinson年化波动率: {parkinson_vol:.2%}")

# 正态分布假设下的价格区间
current_price = df['收盘'].iloc[-1]
upper_1sigma = current_price * (1 + annual_vol)
lower_1sigma = current_price * (1 - annual_vol)
print(f"\n当前价格: {current_price:.2f}")
print(f"1个标准差区间: [{lower_1sigma:.2f}, {upper_1sigma:.2f}]")
```

## 常见误区

1. **"波动率等于亏损"** — 波动率衡量的是价格变动的幅度，不区分涨跌。股价涨10%和跌10%都会增加波动率。上行波动（赚钱的波动）也会推高波动率。
2. **"低波动率就是安全"** — 低波动率可能是因为流动性差（无人交易导致价格不动），或者处于盘整期即将爆发。VIX（恐慌指数）长期处于低位时，往往预示着即将到来的大波动。
3. **"年化波动率 = 日波动率 x 252"** — 正确的是乘以 $\sqrt{252}$ 而不是252。这是因为方差可加（乘以252），但标准差是方差的平方根（所以乘以√252）。
