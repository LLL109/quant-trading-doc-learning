# 收益率

> 收益率是衡量投资回报的最基本指标，是所有量化分析的起点。

## 定义

收益率（Return Rate）是衡量投资收益相对于投资本金的比率，通常以百分比表示。它是评价投资表现的最基本指标，可以应用于单只股票、基金、投资组合乃至整个市场。

对程序员来说，收益率就是投资的"性价比指标"——投入100元，赚了多少元，用百分比来衡量标准化的回报。

## 核心内容

### 简单收益率

简单收益率（Simple Return）是最直观的收益率计算方式：

$$R_t = \frac{P_t - P_{t-1}}{P_{t-1}} = \frac{P_t}{P_{t-1}} - 1$$

- 股价从10元涨到11元，收益率 = (11-10)/10 = 10%
- 股价从11元跌回10元，收益率 = (10-11)/11 = -9.09%
- 注意：涨10%再跌9.09%并不回到原点，这就是简单收益率的不对称性

### 日收益率

日收益率是量化交易中最常用的收益率：
$$R_{\text{日}} = \frac{\text{今日收盘价} - \text{昨日收盘价}}{\text{昨日收盘价}}$$

日收益率是构建所有更长时间周期收益率的基础。

### 累计收益率

累计收益率衡量从起点到终点的总回报：
$$R_{\text{累计}} = \frac{P_{\text{终}} - P_{\text{初}}}{P_{\text{初}}} = \prod_{t=1}^{T}(1 + R_t) - 1$$

### 对数收益率

对数收益率（Log Return）在量化分析中更常用：
$$r_t = \ln\left(\frac{P_t}{P_{t-1}}\right) = \ln(P_t) - \ln(P_{t-1})$$

对数收益率的优点：
1. **可加性**：多期对数收益率可以直接相加 = 长期对数收益率
2. **对称性**：涨10%的对数收益率和跌10%的绝对值相同
3. **正态性假设**：通常假设对数收益率服从正态分布
4. **连续复利**：与连续复利模型天然适配

### 举例说明

股价走势：10元 → 12元 → 11元

**简单收益率：**
- 第1期：(12-10)/10 = 20%
- 第2期：(11-12)/12 = -8.33%
- 两期简单收益率之和 = 20% + (-8.33%) = 11.67% ≠ 累计收益率

**累计收益率：**
- (11-10)/10 = 10%
- 或 (1+20%) x (1-8.33%) - 1 = 10%

**对数收益率：**
- 第1期：ln(12/10) = 18.23%
- 第2期：ln(11/12) = -8.70%
- 两期对数收益率之和 = 18.23% + (-8.70%) = 9.53%
- 验证：ln(11/10) = 9.53% ✓

## 计算公式

**简单收益率：**
$$R_t = \frac{P_t - P_{t-1}}{P_{t-1}}$$

**对数收益率：**
$$r_t = \ln\left(\frac{P_t}{P_{t-1}}\right)$$

**累计收益率：**
$$R_{\text{累计}} = \prod_{t=1}^{T}(1 + R_t) - 1$$

**对数收益率与简单收益率的换算：**
$$r = \ln(1 + R)$$
$$R = e^r - 1$$

## Python 代码

```python
import akshare as ak
import pandas as pd
import numpy as np

# 获取股票数据
df = ak.stock_zh_a_hist(symbol="600519", period="daily",
                         start_date="20240101", end_date="20240630",
                         adjust="qfq")

# 计算简单收益率
df['简单收益率'] = df['收盘'].pct_change()

# 计算对数收益率
df['对数收益率'] = np.log(df['收盘'] / df['收盘'].shift(1))

# 计算累计收益率
df['累计收益率_简单'] = (1 + df['简单收益率']).cumprod() - 1
df['累计收益率_对数'] = df['对数收益率'].cumsum()

# 验证两者关系
print("简单累计收益率:", df['累计收益率_简单'].iloc[-1])
print("对数累计收益率:", df['累计收益率_对数'].iloc[-1])
print("exp(对数累计)-1:", np.exp(df['累计收益率_对数'].iloc[-1]) - 1)

# 收益率统计
print("\n日收益率统计:")
print(df['简单收益率'].describe())

# 正收益日和负收益日
positive_days = (df['简单收益率'] > 0).sum()
negative_days = (df['简单收益率'] < 0).sum()
print(f"\n正收益日: {positive_days}, 负收益日: {negative_days}")
print(f"正收益日比例: {positive_days / (positive_days + negative_days):.2%}")
```

## 常见误区

1. **"收益率可以简单相加"** — 多期简单收益率不能直接相加。涨10%再跌10%不等于0%，而是亏1%（(1+10%)*(1-10%) = 99%）。计算累计收益必须用连乘（复利公式）。
2. **"对数收益率和简单收益率差不多"** — 短期内两者确实接近，但长期累积后差异显著。对数收益率的可加性使其在统计分析和模型构建中更有优势。
3. **"收益率高就是好策略"** — 收益率必须结合风险来看。一个年化50%但最大回撤80%的策略，不如年化20%但最大回撤10%的策略。风险调整后的收益才是真正的评价标准。
