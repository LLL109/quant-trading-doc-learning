# 基金

> 基金是将众多投资者的资金汇集起来，由专业机构进行投资管理的集合投资方式。

## 定义

基金（Fund）是一种利益共享、风险共担的集合投资方式。基金管理公司通过发行基金份额，将众多投资者的资金集中起来，由基金托管人托管、基金管理人管理和运用资金，投资于股票、债券等金融工具。

对程序员来说，基金就像一个"微服务集群"——多台机器（投资者）把资源（资金）汇聚起来，由一个调度器（基金经理）统一管理和分配。

## 核心内容

### 基金分类

**按运作方式分：**

| 类型 | 特点 | 交易方式 |
|------|------|---------|
| 开放式基金 | 规模不固定，可随时申购赎回 | 按净值申赎 |
| 封闭式基金 | 规模固定，有封闭期 | 在交易所买卖 |

**按募集方式分：**

| 类型 | 投资门槛 | 监管要求 | 信息披露 |
|------|---------|---------|---------|
| 公募基金 | 低（1元起） | 严格 | 充分 |
| 私募基金 | 高（100万元起） | 宽松 | 有限 |

**按投资标的分：**

1. **股票型基金**：80%以上资产投资于股票
2. **债券型基金**：80%以上资产投资于债券
3. **混合型基金**：同时投资股票和债券，比例灵活
4. **货币市场基金**：投资于短期货币工具，风险最低（如余额宝）
5. **指数型基金**：跟踪特定指数，属于被动管理型基金

### 基金净值

基金净值（NAV，Net Asset Value）是基金资产减去负债后的余额除以基金份额总数：

$$\text{单位净值} = \frac{\text{基金总资产} - \text{基金总负债}}{\text{基金份额总数}}$$

- **申购**：以未知净值买入（T日提交，T日收盘后才知道净值）
- **赎回**：以未知净值卖出

### 基金费用

| 费用类型 | 说明 | 典型费率 |
|---------|------|---------|
| 申购费 | 买入时收取 | 0.1%-1.5% |
| 赎回费 | 卖出时收取 | 0%-1.5%（持有时间越长越低） |
| 管理费 | 每日从净值中扣除 | 0.5%-1.5%/年 |
| 托管费 | 每日从净值中扣除 | 0.1%-0.25%/年 |

### 举例说明

假设你用10000元申购某基金，申购费率为1.5%：
- 申购费 = 10000 x 1.5% = 150元
- 实际投资金额 = 10000 - 150 = 9850元
- 假设当日净值为2.00元，则获得份额 = 9850 / 2.00 = 4925份
- 持有半年后净值涨到2.20元，赎回费率为0.5%
- 赎回金额 = 4925 x 2.20 x (1 - 0.5%) = 10782.35元
- 收益 = 10782.35 - 10000 = 782.35元

## 计算公式

**基金收益率：**
$$\text{收益率} = \frac{\text{期末净值} - \text{期初净值}}{\text{期初净值}} \times 100\%$$

**申购份额：**
$$\text{申购份额} = \frac{\text{申购金额} \times (1 - \text{申购费率})}{\text{申购日单位净值}}$$

**赎回金额：**
$$\text{赎回金额} = \text{赎回份额} \times \text{赎回日单位净值} \times (1 - \text{赎回费率})$$

## Python 代码

```python
import akshare as ak
import pandas as pd

# 获取基金列表
fund_list = ak.fund_open_fund_info_em()
print(fund_list.head())

# 获取基金净值数据
fund_nav = ak.fund_open_fund_info_em(symbol="000001", indicator="单位净值走势")
print(fund_nav.head(10))

# 计算申购份额和赎回金额
def calc_purchase(amount, nav, fee_rate=0.015):
    """计算申购份额"""
    fee = amount * fee_rate
    shares = (amount - fee) / nav
    return shares, fee

def calc_redeem(shares, nav, fee_rate=0.005):
    """计算赎回金额"""
    amount = shares * nav
    fee = amount * fee_rate
    return amount - fee, fee

# 示例
purchase_shares, purchase_fee = calc_purchase(10000, 2.00, 0.015)
print(f"申购金额: 10000元, 申购费: {purchase_fee}元, 获得份额: {purchase_shares:.2f}份")

redeem_amount, redeem_fee = calc_redeem(purchase_shares, 2.20, 0.005)
print(f"赎回金额: {redeem_amount:.2f}元, 赎回费: {redeem_fee:.2f}元")
print(f"投资收益: {redeem_amount - 10000:.2f}元")
```

## 常见误区

1. **"基金净值低就是便宜"** — 基金净值代表基金的历史业绩，不代表未来表现。1元的基金不一定比3元的基金更有上涨空间。选择基金应看投资策略和管理能力，而非净值高低。
2. **"新基金比老基金好"** — 新基金存在建仓期（通常1-3个月），期间无法充分享受市场上涨。老基金已有持仓，可以立即跟踪市场。新基金的"1元净值"也不代表便宜。
3. **"分红越多的基金越好"** — 基金分红只是把净值的一部分以现金形式返还给投资者，并不增加总收益。分红后净值等额下降，分红前后的总资产不变。
