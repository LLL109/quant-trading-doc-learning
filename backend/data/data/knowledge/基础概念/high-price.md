# 最高价

> 最高价是一段时间内市场愿意出价的上限，是衡量多方力量极限和阻力位的重要参考。

## 定义

最高价（High Price）是指在一个交易日（或其他时间周期内）所达到的最高成交价格。最高价出现在盘中某个时刻，代表了多方在该时间段内所能推动价格到达的最高水平。

对程序员来说，最高价就像一个系统的"峰值负载"——它告诉你系统在极端情况下能达到的上限。

## 核心内容

### 最高价的形成

最高价通常出现在以下场景：
1. **开盘后的快速拉升**：隔夜利好推动开盘后快速冲高
2. **盘中消息刺激**：突发利好消息（如政策出台、公司公告）
3. **主力资金拉升**：大资金主动买入推动价格上涨
4. **技术突破**：价格突破关键阻力位引发跟风买入

### 上影线的含义

上影线是K线中从实体上端（阳线的收盘价或阴线的开盘价）到最高价之间的线段。

| 上影线长度 | 含义 | 信号 |
|-----------|------|------|
| 无上影线 | 收盘价就是最高价 | 强势，多方完全占优 |
| 短上影线 | 高位有少量抛压 | 正常，趋势可能延续 |
| 长上影线 | 高位有大量抛压 | 弱势，可能见顶回落 |

### 阻力位参考

历史最高价常常构成阻力位（Resistance Level）：
- 当价格接近前期高点时，之前在高位套牢的投资者可能选择卖出解套
- 形成"双重顶"或"三重顶"等形态
- 如果放量突破前期高点，可能形成新的上升空间

### N日最高价

量化交易中常用的指标：
- **N日最高价**：过去N个交易日的最高价的最大值
- 用于计算布林带上轨、通道突破策略等

### 举例说明

某股票当日报收情况：
- 开盘10.00元，盘中最高10.80元，收盘10.20元
- 上影线长度 = 10.80 - 10.20 = 0.60元
- 实体长度 = 10.20 - 10.00 = 0.20元
- 上影线是实体的3倍，说明上方抛压很重
- 次日如果没有放量突破10.80元，可能继续回落

再比如，某股票近20日最高价为15.00元，当前价格14.80元：
- 15.00元是近期阻力位
- 如果放量突破15.00元，可能开启新一波上涨
- 如果多次冲击15.00元未果，可能形成双顶

## 计算公式

**N日最高价：**
$$\text{High}_N = \max(\text{High}_1, \text{High}_2, ..., \text{High}_N)$$

**上影线长度：**
$$\text{上影线} = \text{最高价} - \max(\text{开盘价}, \text{收盘价})$$

**上影线比例：**
$$\text{上影线比例} = \frac{\text{上影线长度}}{\text{最高价} - \text{最低价}}$$

## Python 代码

```python
import akshare as ak
import pandas as pd

# 获取股票日K线
df = ak.stock_zh_a_hist(symbol="600519", period="daily",
                         start_date="20240101", end_date="20240630",
                         adjust="qfq")

# 计算N日最高价
df['20日最高'] = df['最高'].rolling(20).max()
df['60日最高'] = df['最高'].rolling(60).max()

# 计算上影线
df['上影线'] = df['最高'] - df[['开盘', '收盘']].max(axis=1)
df['实体'] = abs(df['收盘'] - df['开盘'])
df['振幅'] = df['最高'] - df['最低']
df['上影线比例'] = df['上影线'] / df['振幅']

# 筛选长上影线（上影线比例>50%且振幅>2%）
df['振幅_pct'] = df['振幅'] / df['收盘'].shift(1) * 100
long_upper = df[(df['上影线比例'] > 0.5) & (df['振幅_pct'] > 2)]
print(f"长上影线天数: {len(long_upper)}")
print(long_upper[['日期', '开盘', '收盘', '最高', '最低', '上影线比例']].head())

# 识别突破前期高点
lookback = 20
df['前期高点'] = df['最高'].shift(1).rolling(lookback).max()
df['突破高点'] = (df['收盘'] > df['前期高点']) & (df['收盘'].shift(1) <= df['前期高点'].shift(1))
print(f"\n突破20日高点次数: {df['突破高点'].sum()}")
print(df[df['突破高点']][['日期', '收盘', '前期高点']].head())
```

## 常见误区

1. **"最高价一定是最好的卖点"** — 最高价只是事后才知道的，在盘中你无法提前知道最高价在哪里。试图"卖在最高点"是不现实的，应该追求"买在合理价位，卖在合理价位"。
2. **"突破前期高点就一定继续涨"** — 突破可能失败（假突破）。真正有效的突破需要成交量配合，且突破后价格应站稳在前期高点上方。
3. **"日内最高价和K线最高价是一回事"** — 在日K线上确实是同一件事。但在周K线或月K线上，周期内的最高价是指该周期内所有交易日的最高价中的最大值。
