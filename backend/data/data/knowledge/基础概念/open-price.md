# 开盘价

> 开盘价是一天交易的起点，由集合竞价产生，反映了隔夜信息消化后的市场预期。

## 定义

开盘价（Open Price）是指证券在每个交易日第一笔成交的价格。在A股市场中，开盘价通过开盘集合竞价（9:15-9:25）产生，而非直接取第一笔成交价。开盘价是K线图中最重要的四个价格之一，位于K线实体的上端（阳线）或下端（阴线）。

对程序员来说，开盘价就像一个"系统的初始化值"——它是当天价格波动的起始基准点。

## 核心内容

### 集合竞价如何产生开盘价

开盘集合竞价的规则如下：

1. **收集委托**（9:15-9:25）：投资者提交买卖委托单
2. **确定开盘价**：交易所按照最大成交量原则计算一个统一价格
3. **全部成交**：所有符合条件的委托以此价格一次性撮合

最大成交量原则的具体步骤：
- 对每个可能的价格P，计算：
  - 高于P的买单总量（全部能成交）
  - 低于P的卖单总量（全部能成交）
  - 等于P的买卖单中至少一方全部成交
- 使成交量最大的价格即为开盘价
- 如果有多个价格使成交量相同，取与昨收价最近的价格

### 集合竞价的时间窗口

| 时间 | 能否下单 | 能否撤单 | 说明 |
|------|---------|---------|------|
| 9:15-9:20 | 能 | 能 | 可以试探性报价 |
| 9:20-9:25 | 能 | 不能 | 下单要慎重，无法反悔 |
| 9:25 | - | - | 确定开盘价，撮合成交 |
| 9:25-9:30 | 不能 | 不能 | 静默期 |

### 开盘价对日内走势的影响

开盘价的高低反映了隔夜消息（海外市场、政策公告、公司公告等）对市场的影响：

1. **高开**（开盘价 > 昨收价）：利好消息刺激或市场情绪乐观
   - 高开后继续上涨 = 强势延续
   - 高开后回落 = 可能是"诱多"
   
2. **低开**（开盘价 < 昨收价）：利空消息或市场恐慌
   - 低开后继续下跌 = 弱势延续
   - 低开后反弹 = 可能是"诱空"
   
3. **平开**（开盘价 ≈ 昨收价）：无重大消息影响

### 常见的开盘策略

量化交易中常见的基于开盘价的策略：

- **开盘跳空策略**：利用开盘价与昨收盘的跳空缺口进行交易
- **集合竞价分析**：分析集合竞价阶段的委托量变化，判断多空力量
- **开盘区间突破策略**：等待开盘后价格突破开盘价一定幅度时入场

### 举例说明

某股票昨收价10.00元：
- 隔夜发布利好公告（如业绩预增50%）
- 集合竞价阶段大量买单涌入，最终以10.50元开盘（高开5%）
- 如果开盘后价格持续在10.50上方运行，说明利好被充分认可
- 如果开盘后价格迅速回落到10.00附近，可能是"高开低走"，利好被兑现

## 计算公式

**开盘价跳空幅度：**
$$\text{跳空幅度} = \frac{\text{开盘价} - \text{昨收价}}{\text{昨收价}} \times 100\%$$

**开盘区间（用于开盘区间突破策略）：**
$$\text{开盘区间高点} = \max(\text{前N根K线的最高价})$$
$$\text{开盘区间低点} = \min(\text{前N根K线的最低价})$$

常见N=15（开盘后15分钟），即9:30-9:45的价格区间。

## Python 代码

```python
import akshare as ak
import pandas as pd

# 获取股票日K线数据
df = ak.stock_zh_a_hist(symbol="600519", period="daily",
                         start_date="20240101", end_date="20240630",
                         adjust="qfq")

# 计算开盘价跳空幅度
df['跳空幅度'] = (df['开盘'] - df['收盘'].shift(1)) / df['收盘'].shift(1)

# 统计高开、低开、平开的比例
df['开盘类型'] = df['跳空幅度'].apply(
    lambda x: '高开' if x > 0.005 else ('低开' if x < -0.005 else '平开'))
print("开盘类型统计:")
print(df['开盘类型'].value_counts())

# 分析高开后当日走势
df['日内涨跌'] = (df['收盘'] - df['开盘']) / df['开盘']
high_open = df[df['开盘类型'] == '高开']
print(f"\n高开样本数: {len(high_open)}")
print(f"高开后继续上涨比例: {(high_open['日内涨跌'] > 0).mean():.2%}")
print(f"高开后平均日内涨跌: {high_open['日内涨跌'].mean():.2%}")

# 开盘跳空策略回测（简化版）
df['策略信号'] = 0
df.loc[df['跳空幅度'] < -0.02, '策略信号'] = 1   # 大幅低开买入
df.loc[df['跳空幅度'] > 0.03, '策略信号'] = -1  # 大幅高开卖出
df['策略收益'] = df['策略信号'].shift(1) * df['涨跌幅'] / 100
print(f"\n开盘跳空策略累计收益: {(1 + df['策略收益'].dropna()).cumprod().iloc[-1] - 1:.2%}")
```

## 常见误区

1. **"开盘价就是第一笔成交价"** — 在A股市场中，开盘价是集合竞价确定的价格，而非9:30后的第一笔成交价。9:25确定的集合竞价成交价才是开盘价。
2. **"高开就一定会涨"** — 高开只代表开盘时的多方力量强，不代表全天走势。很多情况下高开后会回落（"冲高回落"），特别是当高开幅度很大时。
3. **"开盘价和昨收价一样就是平开"** — 严格来说，平开是指开盘价与昨收价完全相同。但由于实际交易中这种情况极少，通常将跳空幅度在±0.5%以内的都称为"平开"。
