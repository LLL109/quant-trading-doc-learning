# 最低价

> 最低价是一段时间内市场价格的下边界，是衡量空方力量极限和支撑位的重要参考。

## 定义

最低价（Low Price）是指在一个交易日（或其他时间周期内）所达到的最低成交价格。最低价出现在盘中某个时刻，代表了空方在该时间段内所能将价格打压到的最低水平。

对程序员来说，最低价就像一个系统的"最低水位线"——它告诉你系统在最坏情况下的下限。

## 核心内容

### 最低价的形成

最低价通常出现在以下场景：
1. **恐慌性抛售**：利空消息引发大量卖单
2. **止损盘集中触发**：价格跌破关键支撑位，止损单集中执行
3. **主力洗盘**：大资金故意打压股价，洗出散户
4. **尾盘杀跌**：收盘前突然出现的大量卖单

### 下影线的含义

下影线是K线中从实体下端（阳线的开盘价或阴线的收盘价）到最低价之间的线段。

| 下影线长度 | 含义 | 信号 |
|-----------|------|------|
| 无下影线 | 开盘价（阴线）或收盘价（阳线）就是最低价 | 弱势，空方完全占优 |
| 短下影线 | 低位有少量买盘 | 正常，趋势可能延续 |
| 长下影线 | 低位有大量买盘承接 | 强势，可能见底反弹 |

### 支撑位参考

历史最低价常常构成支撑位（Support Level）：
- 当价格接近前期低点时，认为价格"便宜"的投资者可能选择买入
- 形成"双重底"或"三重底"等底部形态
- 如果放量跌破前期低点，可能开启新的下跌空间

### N日最低价

量化交易中常用的指标：
- **N日最低价**：过去N个交易日的最低价的最小值
- 用于计算布林带下轨、通道下轨等

### 举例说明

某股票当日报收情况：
- 开盘10.50元，盘中最低9.80元，收盘10.40元
- 下影线长度 = 10.40 - 9.80 = 0.60元（因为收盘>开盘，下影线从开盘价算起不对，应为 min(开盘,收盘) - 最低 = 10.40 - 9.80 = 0.60）

更准确的示例：
- 开盘10.50元，收盘10.40元（阴线），最低9.80元
- 下影线 = 10.40 - 9.80 = 0.60元（阴线下影线从收盘价算）
- 实体 = 10.50 - 10.40 = 0.10元
- 下影线是实体的6倍，说明低位有强劲买盘支撑
- 这种形态叫"锤子线"，是潜在的见底信号

## 计算公式

**N日最低价：**
$$\text{Low}_N = \min(\text{Low}_1, \text{Low}_2, ..., \text{Low}_N)$$

**下影线长度：**
$$\text{下影线} = \min(\text{开盘价}, \text{收盘价}) - \text{最低价}$$

**下影线比例：**
$$\text{下影线比例} = \frac{\text{下影线长度}}{\text{最高价} - \text{最低价}}$$

## Python 代码

```python
import akshare as ak
import pandas as pd

# 获取股票日K线
df = ak.stock_zh_a_hist(symbol="600519", period="daily",
                         start_date="20240101", end_date="20240630",
                         adjust="qfq")

# 计算N日最低价
df['20日最低'] = df['最低'].rolling(20).min()
df['60日最低'] = df['最低'].rolling(60).min()

# 计算下影线
df['下影线'] = df[['开盘', '收盘']].min(axis=1) - df['最低']
df['实体'] = abs(df['收盘'] - df['开盘'])
df['振幅'] = df['最高'] - df['最低']
df['下影线比例'] = df['下影线'] / df['振幅']

# 筛选长下影线（下影线比例>50%且振幅>2%）
df['振幅_pct'] = df['振幅'] / df['收盘'].shift(1) * 100
long_lower = df[(df['下影线比例'] > 0.5) & (df['振幅_pct'] > 2)]
print(f"长下影线天数: {len(long_lower)}")
print(long_lower[['日期', '开盘', '收盘', '最高', '最低', '下影线比例']].head())

# 识别跌破前期低点
lookback = 20
df['前期低点'] = df['最低'].shift(1).rolling(lookback).min()
df['跌破低点'] = (df['收盘'] < df['前期低点']) & (df['收盘'].shift(1) >= df['前期低点'].shift(1))
print(f"\n跌破20日低点次数: {df['跌破低点'].sum()}")
print(df[df['跌破低点']][['日期', '收盘', '前期低点']].head())

# 计算价格区间宽度
df['区间宽度'] = (df['最高'] - df['最低']) / df['收盘'] * 100
print(f"\n平均日内振幅: {df['区间宽度'].mean():.2f}%")
```

## 常见误区

1. **"最低价就是最佳买入点"** — 最低价是事后才知道的。在盘中，你无法预知最低价在哪里。试图"抄底"往往抄在半山腰。更合理的做法是在合理估值区间内分批建仓。
2. **"跌破前期低点就一定继续跌"** — 跌破可能是假突破（假摔）。真正有效的跌破需要放量配合，且跌破后价格应持续在前期低点下方运行。
3. **"最低价和跌停价是一回事"** — 最低价是盘中实际成交的最低价格，跌停价是交易所规定的当日最低报价限制。最低价可能接近但通常不会恰好等于跌停价。
