# ETF基金

> ETF是在交易所上市交易的指数基金，像买股票一样买一篮子证券。

## 定义

ETF（Exchange Traded Fund，交易型开放式指数基金）是一种在证券交易所上市交易的基金，其份额代表一篮子股票（或其他资产）的所有权。ETF的目标是跟踪特定指数（如沪深300、中证500）的表现，实现被动投资。

对程序员来说，ETF就像一个"预配置的资产包"——你不需要自己挑选每只股票，而是直接买一个已经按权重配置好的组合。

## 核心内容

### ETF的运作机制

ETF结合了封闭式基金和开放式基金的特点：

1. **一级市场**（申购赎回）：机构投资者用一篮子股票向基金公司申购ETF份额，或用ETF份额赎回一篮子股票（最小单位通常为50万份或100万份）
2. **二级市场**（买卖）：普通投资者像买卖股票一样在交易所买卖ETF

这种双重机制使得ETF的市场价格始终贴近其净值（NAV），因为当出现折溢价时，机构可以通过一级市场进行套利。

### ETF vs 普通基金

| 对比项 | ETF | 普通开放式基金 |
|--------|-----|---------------|
| 交易方式 | 交易所实时买卖 | 通过基金公司/银行申赎 |
| 交易价格 | 实时市价 | 每日收盘净值 |
| 交易费用 | 低（类似股票佣金） | 较高（申购费1%-1.5%） |
| 跟踪误差 | 小 | 相对较大 |
| 最低投资 | 1手（100份） | 通常1000元起 |

### ETF的主要类型

1. **宽基ETF**：跟踪大盘指数，如沪深300ETF（510300）、中证500ETF（510500）
2. **行业ETF**：跟踪特定行业指数，如半导体ETF、新能源ETF、医药ETF
3. **跨境ETF**：投资海外市场，如恒生科技ETF、纳斯达克100ETF
4. **债券ETF**：跟踪债券指数，如国债ETF、城投债ETF
5. **商品ETF**：跟踪商品价格，如黄金ETF（518880）

### ETF套利机制

当ETF二级市场价格与净值出现偏差时：
- **溢价套利**（市价 > 净值）：在一级市场用股票申购ETF份额，然后在二级市场卖出
- **折价套利**（市价 < 净值）：在二级市场买入ETF份额，然后在一级市场赎回股票

### 举例说明

假设你想投资沪深300指数：
- **方案A**：自己按权重买入300只股票——资金需求巨大，操作复杂
- **方案B**：买入沪深300ETF（510300）——只需几百元，交易方式和股票完全一样

买入1000份沪深300ETF，假设价格4.5元/份：
- 总成本 = 1000 x 4.5 = 4500元
- 相当于间接持有沪深300指数中300只股票的组合
- 如果沪深300指数涨5%，ETF大约也涨5%，你赚约225元

## 计算公式

**ETF净值（NAV）：**
$$\text{NAV} = \frac{\text{基金持有的所有资产市值总和} - \text{负债}}{\text{ETF总份额}}$$

**折溢价率：**
$$\text{折溢价率} = \frac{\text{市场价格} - \text{NAV}}{\text{NAV}} \times 100\%$$

**跟踪误差：**
$$\text{跟踪误差} = \text{std}(R_{\text{ETF}} - R_{\text{指数}})$$

其中 $R_{\text{ETF}}$ 是ETF的日收益率，$R_{\text{指数}}$ 是标的指数的日收益率。

## Python 代码

```python
import akshare as ak
import pandas as pd

# 获取ETF列表
etf_list = ak.fund_etf_spot_em()
print(etf_list[['代码', '名称', '最新价', '涨跌幅']].head(10))

# 获取某只ETF的历史行情
etf_hist = ak.fund_etf_hist_em(symbol="510300", period="daily",
                                start_date="20240101", end_date="20240630",
                                adjust="qfq")
print(etf_hist[['日期', '开盘', '收盘', '最高', '最低', '成交量']].head())

# 计算ETF的日收益率和累计收益
etf_hist['日收益率'] = etf_hist['收盘'].pct_change()
etf_hist['累计收益率'] = (1 + etf_hist['日收益率']).cumprod() - 1

print(f"期间累计收益率: {etf_hist['累计收益率'].iloc[-1]:.2%}")
print(f"年化波动率: {etf_hist['日收益率'].std() * (252**0.5):.2%}")

# 对比不同ETF的表现
etfs = {'沪深300': '510300', '中证500': '510500', '创业板': '159915'}
results = {}
for name, code in etfs.items():
    df = ak.fund_etf_hist_em(symbol=code, period="daily",
                              start_date="20240101", end_date="20240630",
                              adjust="qfq")
    total_ret = (df['收盘'].iloc[-1] / df['收盘'].iloc[0]) - 1
    results[name] = f"{total_ret:.2%}"

print("各ETF期间收益率:")
for k, v in results.items():
    print(f"  {k}: {v}")
```

## 常见误区

1. **"ETF都是跟踪指数的被动基金"** — 虽然大多数ETF是被动指数基金，但也存在主动管理型ETF。另外，杠杆ETF（2倍、3倍）和反向ETF（做空）并不适合长期持有，因为每日再平衡会导致长期表现偏离预期。
2. **"ETF不会有跟踪误差"** — ETF会因为管理费、现金拖累（预留现金应对赎回）、成分股调整等原因产生跟踪误差，通常年化在0.5%-2%之间。
3. **"买ETF就等于分散投资"** — 行业ETF和主题ETF的风险集中度很高，只有宽基ETF（如沪深300、中证500）才具有较好的分散效果。
